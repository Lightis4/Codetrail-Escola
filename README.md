# CodeTrail Escola 6.0 — edição pedagógica

Plataforma comunitária gratuita para estudar fundamentos, C e C++.

## Atualização desta edição
- Preserva a base Spring Boot e as 84 aulas anteriores.
- Aprofunda **9 aulas prioritárias** de fundamentos, C e C++ com teoria específica, execução comentada, práticas e perguntas de revisão.
- Substitui os exemplos de variáveis em C e strings em C++ por programas didáticos completos, comentados linha a linha.
- Refina a identidade visual editorial e melhora a legibilidade do CSS.
- Mantém os exercícios e o progresso existentes.

## Executar
Use Java 21 e Maven 3.10+:

```powershell
cd backend
mvn clean spring-boot:run
```

Abra http://localhost:8080.

## Limitações e próximos passos
A plataforma ainda não possui correção automática segura de código C/C++, nem banco de dados Neon configurado para produção. As demais aulas preservam o conteúdo da versão 5.0 e precisam de revisão editorial individual antes da publicação pública. Não envie credenciais para o repositório.
